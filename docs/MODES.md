# DeepCode Modes (V1.0.0)

DeepCode exposes explicitly constrained interaction paths natively across the CLI/TUI loops via the `/mode` boundaries.

## `/ask`
**Best for**: Explanations, architectural inquiries, or factual lookups.
- **Write Engine**: **DISABLED**. Safe execution domain completely restricting file mutations seamlessly.
- **UX Streaming**: Enabled naturally allowing fluid text injection instantly bypassing token loops!
- **Test Generation/Sandboxes**: Skipped entirely avoiding irrelevant Bash noise contexts safely.

## `/plan`
**Best for**: Deep repository overviews, workflow step-by-steps natively prior to modifying domains!
- **Write Engine**: **DISABLED**.
- **Memory Optimization**: K-bound retrieval strictly reduced (`rag_top_k` clamped natively) preventing context flooding.
- **UX Streaming**: Enabled dynamically capturing intermediate planning domains globally formatting lists dynamically!

## `/build`
**Best for**: Generating `<patch>` logic limits, autonomous loop tracking, and automated refactors organically.
- **Write Engine**: **ENABLED**. Activates strict FileWrite limits checking scopes mapping targets successfully extracting `uuid` branching dynamically natively.
- **UX Streaming**: **DISABLED**. Pre-buffered rendering strictly resolving multi-file extraction diff blocks precisely isolating chunking UI tearing flawlessly! 
- **Validation Track**: Sandboxes test run logic inherently looping back into the Critic limit natively preventing silent test failures dynamically!
